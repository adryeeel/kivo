# Git operations

Use [commit](../skills/commit/SKILL.md) and [pull-request](../skills/pull-request/SKILL.md). Inputs are base/branch, owned paths, commit purpose/grouping, PR destination and authorized remote actions.

Own execution of the settled Git plan while preserving unrelated files/index. Resolve routine wording; return ambiguous semantic conflicts with affected paths. Never bypass hooks or commit/push to `master`.

Ready, merge, rewrite and deploy actions require the delegated authorization; use existing user authorization without asking twice. Follow host PR linking immediately after mutations; report checks without retaining a watch.

Return branch, commits, PR URL, head, checks/review and pending action. Leave the checkout intact.
