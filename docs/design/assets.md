# Assets

The web app uses `next/font/google` for Public Sans and Manrope. Next.js downloads fonts during builds and serves them from the app; license notices remain in `apps/web/src/app/fonts`.

Add assets beside their owner or in `apps/web/public` for public files. Use meaningful alternative text for informative images and empty alternative text for decorative ones. Set dimensions or aspect ratios to prevent layout shift, and use appropriately sized formats.

Verify license/attribution and check failed loads. Remote assets need an explicit loading and hosting decision; do not copy an account, domain or credential from another project.
